# 牙科好评生成器 · GitHub Pages 部署包

单文件静态站点，无后端、无外部依赖（二维码库已本地化）。顾客扫码 → 复制 → 粘贴美团，零手动打字、零隐私交换。

## 文件说明
- `index.html` —— 生成端 + 顾客查看端（同一文件自动切换）
- `qrcode.min.js` —— 本地二维码库（不依赖 CDN，国内可达）
- `.nojekyll` —— 禁用 GitHub Pages 的 Jekyll 处理，确保静态文件原样托管

## 部署到 GitHub Pages（免费，仓库可私有）

### 1. 新建仓库
- 在 GitHub 新建仓库（可设为 **Private**：Pages 站点仍会公开，但源码不公开）。
- 把 `index.html`、`qrcode.min.js`、`.nojekyll` 三个文件推到仓库根目录（建议分支 `main`）。

### 2. 开启 Pages
- 仓库 → **Settings（设置）** → **Pages**。
- Build and deployment → Source 选 **Deploy from a branch**。
- Branch 选 `main` / `(root)` → **Save**。
- 等待约 1 分钟构建，得到链接：
  ```
  https://<你的用户名>.github.io/<仓库名>/
  ```

### 3. 后续更新
- 改完文件重新 `push` 即**自动重新部署**（无需手动点更新）。

## 日常使用
1. 用上面的 `github.io` 链接打开生成端（手机/电脑浏览器均可）。
2. 选牙科项目 → 点「AI 生成好评」→ 屏幕展示二维码。
3. 顾客用**微信或相机**扫码 → 打开网页 → 点「一键复制」→ 粘贴美团。

## 接入真实 AI（可选）
- 页面勾选「接入真实 AI 生成」→ 填 API Base / Key / 模型（OpenAI 格式）→ 点「保存配置」（仅存本机浏览器）。
- 未配置或调用失败时自动回退模板。

### 重要限制（CORS）
- 纯静态页浏览器直连国内大模型常遇**跨域(CORS)**限制（DeepSeek、通义、智谱等默认不允许），会报错并回退模板。
- 最稳方式：用 **WorkBuddy** 生成好评 → 粘贴进文本框 → 生成二维码（零 CORS、零密钥）。

## 注意
- 国内访问 `github.io` 可能偏慢或偶发超时，顾客扫码打开页面时请留意；如需国内稳定，可改挂 Gitee Pages 或七牛/腾讯云对象存储（默认域名免备案）。
- 必须用部署链接打开生成端；本地 `file://` 生成的二维码顾客手机打不开。
- API Key 仅存本机浏览器，换设备/清缓存需重填；勿在公共设备保存。
